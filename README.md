# SV Solutions

The current production site is in [`version6/`](version6/README.md). It is an Astro 5 static website for **SV Solutions — Materials & Surface Engineering**, configured for **https://svsolutions.pro** at the domain root.

```bash
cd version6
npm ci
npm run dev
```

See the [content manual](version6/CONTENT_GUIDE.md), [brand guide](version6/BRAND_GUIDE.md) and [deployment instructions](version6/DEPLOYMENT.md).

`ver5/` is a historical reference, not part of the production build. Configure the hosting provider's project root as `version6`.
